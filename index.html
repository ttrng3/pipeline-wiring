The flow

All nine pipelines are built in this order. The artifact is the last step, never the source, and never a step that can block the repo write.

schedule → cloud routine → source ↓ GitHub ↓ Pages (truth) ↓ artifact (mirror)

Two links, and they are not the same thing. The address is the Pages URL — that is what goes in a document, an email or a message. The Cowork link opens the preview of that same page inside Claude. The artifacts stay private either way: a link alone opens nothing for anyone you have not shared it with.

6 · Done — the 24/09 change log, as written then

Open the 24/09 log. Two lines in it are now wrong, and are marked.

The flow is now uniform across all seven. Each routine writes its source into GitHub, Pages serves it, and the mirror publishes last. A failed mirror reports and stops — it can never cause an undo, retry or rewrite of the repo.

Every mirror was verified, not assumed. Fragments built with zero doctype/<html>/<head>/<body> tags; data files published first and the page second on the larger payloads, because a page sent alongside a big files payload comes back blank; exactly one <html> tag on read-back.

Five renderers fetch data/ relatively and only fall back to the absolute Pages URL — which CSP blocks inside an artifact. That is why each mirror carries its own data/ copy. GDSH is the exception: build_auto.py bakes the numbers in and it fetches nothing, so there the mirror is the page. Each routine now carries that distinction in writing.

Superseded Audit publisher moved 02:00 → 04:00 Monday. Since then the publisher became Part B of the monthly system run (1st 03:00), and the old publisher is a fallback on the 2nd at 01:00. It used to fire one hour before its own producer, so whenever the 1st fell on a Monday the fresh audit waited a week — 2027-02-01, 2027-03-01, 2027-11-01. Now one hour behind, with the reason written into the prompt so nobody moves it back.

GDSH renamed to “weekly check, monthly period” — the cron was always weekly. Typo fixed: SINH BẮNG CODE → SINH BẰNG CODE.

Three plaintext credential files moved to Drive trash — a github_pat_…, an sk-ant-oat01-…, and a third PAT-shaped file.

Japan Pages switched off — the public URL 404s; the repo is untouched.

Ops-Dashboard restyled to the Ty Artifact Standard — it was the last page on the retired palette. Variable names were kept, because ksnb-render.js builds its SVG charts from them and writes color:var(--red) onto 12.5px table numbers; so every accent is now a text-safe ink (blue 8.2:1, red 6.6:1, amber 6.4:1, green 6.6:1 on white) rather than a bright mark. Chart pairs checked with the CVD validator: blue/red ΔE 24.3, blue/amber 25.9, green/red 7.0 deutan — the last is legal because the bars also encode sign by position around a zero axis and the MoM table repeats every signed figure. Nothing outside the stylesheet changed; the file is otherwise byte-identical.

That restyle fixed a real defect. The old sheet carried a second, dead :root block from the 20/09 reskin that aliased --blue and --green to the same colour. Anywhere both appeared — the info vs good bullet dots, the KPI border tops — they were indistinguishable. They are now two distinct hues.

Ops-Dashboard became the eighth pipeline. The repo was already repo-first with a runbook, heartbeat and freshness check — but no routine had ever been created, so it only moved when run by hand. It now has one. Superseded not Mondays: the live cron is 0 6 1,15 * *, the 1st and 15th.

Its "mounted folder" was never a Mac dependency. The source it calls thư mục Drive cục bộ 09 TCKT is a Google Drive folder the connector reads from the cloud (since 2026-09-25 at 08 Omni Service - OMNI/09 TCKT, same folderId) — the same false constraint Trade Journal had. Fixed 25/09 Second Brain, Applied had silently stopped refreshing

Its owner was KB Monthly Update, which was folded into Monthly system run (1st, 03:00). The merged prompt kept the republish as Part C step 4 — but the 25/09 test run skipped it, and skipped the Ecosystem Health db-write with it.

The cause is worth knowing, because it will recur elsewhere. The run probed for the Artifact tool with ToolSearch, which searches only deferred tools. An already-attached tool returns “No matching deferred tools found” — so a present tool looks exactly like a missing one. The run read that as unavailable and dropped both artifact steps without flagging it. Artifact and ArtifactData were in its allowed_tools the whole time.

The prompt now states the tools are attached, forbids the ToolSearch probe, marks both steps mandatory, and reports each outcome on its own notification line. This page has no Pages site — the artifact is its only address, so a skipped step shows up nowhere. Next real run: 1 Oct.
