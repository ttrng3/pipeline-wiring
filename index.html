The flow

All eight pipelines are built in this order. The artifact is the last step, never the source, and never a step that can block the repo write.

schedule → cloud routine → source ↓ GitHub ↓ Pages (truth) ↓ artifact (mirror)

Two links, and they are not the same thing. The address is the Pages URL — that is what goes in a document, an email or a message, and it is the one worth remembering. The Cowork link opens the preview of that same page inside Claude. Every row below carries both, so nothing here needs copying by hand. The artifacts stay private either way: a link alone opens nothing for anyone you have not shared it with.

6 · Done

The flow is now uniform across all seven. Each routine writes its source into GitHub, Pages serves it, and the mirror publishes last. A failed mirror reports and stops — it can never cause an undo, retry or rewrite of the repo.

Every mirror was verified, not assumed. Fragments built with zero doctype/<html>/<head>/<body> tags; data files published first and the page second on the larger payloads, because a page sent alongside a big files payload comes back blank; exactly one <html> tag on read-back.

Five renderers fetch data/ relatively and only fall back to the absolute Pages URL — which CSP blocks inside an artifact. That is why each mirror carries its own data/ copy. GDSH is the exception: build_auto.py bakes the numbers in and it fetches nothing, so there the mirror is the page. Each routine now carries that distinction in writing.

Audit publisher moved 02:00 → 04:00 Monday. It used to fire one hour before its own producer, so whenever the 1st fell on a Monday the fresh audit waited a week — 2027-02-01, 2027-03-01, 2027-11-01. Now one hour behind, with the reason written into the prompt so nobody moves it back.

GDSH renamed to “weekly check, monthly period” — the cron was always weekly. Typo fixed: SINH BẮNG CODE → SINH BẰNG CODE.

Three plaintext credential files moved to Drive trash — a github_pat_…, an sk-ant-oat01-…, and a third PAT-shaped file.

Japan Pages switched off — the public URL 404s; the repo is untouched.

Ops-Dashboard restyled to the Ty Artifact Standard — it was the last page on the retired palette. Variable names were kept, because ksnb-render.js builds its SVG charts from them and writes color:var(--red) onto 12.5px table numbers; so every accent is now a text-safe ink (blue 8.2:1, red 6.6:1, amber 6.4:1, green 6.6:1 on white) rather than a bright mark. Chart pairs checked with the CVD validator: blue/red ΔE 24.3, blue/amber 25.9, green/red 7.0 deutan — the last is legal because the bars also encode sign by position around a zero axis and the MoM table repeats every signed figure. Nothing outside the stylesheet changed; the file is otherwise byte-identical.

That restyle fixed a real defect. The old sheet carried a second, dead :root block from the 20/09 reskin that aliased --blue and --green to the same colour. Anywhere both appeared — the info vs good bullet dots, the KPI border tops — they were indistinguishable. They are now two distinct hues.

Ops-Dashboard became the eighth pipeline. The repo was already repo-first with a runbook, heartbeat and freshness check — but no routine had ever been created, so it only moved when run by hand. It now has one, Mondays 06:00 UTC.

Its "mounted folder" was never a Mac dependency. The source it calls thư mục Drive cục bộ 09 TCKT is a Google Drive folder the connector reads from the cloud (since 2026-09-25 at 08 Omni Service - OMNI/09 TCKT, same folderId) — the same false constraint Trade Journal had. Both PnL files are readable; the routine now scans Outlook and that folder, because TCKT has started delivering reports there instead of by email.

Three artifacts became one — Starter Story and Learning Matrix are tabs on this page. One duplicate deleted — the old Ecosystem Audit copy, after confirming the repo already held the same run.

Broken Signal Desk loses its source tonight at 00:10 UTC

signal-desk-collector was deleted on 24/09, but the Signal Desk daily briefing routine still names it as its git source — and its prompt opens "everything you need is in the cloned repo." It reads PUBLISH-CONTRACT.md, BRIEFING-SPEC.md, data/latest.json and the collector's raw file from that repo. With the repo gone it cannot provision, so the run fails before a session exists.

Three ways out, and the choice is yours:

  • Restore the repo. GitHub keeps a deleted repo recoverable for 90 days — Settings → your repositories → Deleted repositories. This is the only option that keeps the briefing working as designed.
  • Disable the routine until you decide. No data is lost; the artifact keeps its last briefing.
  • Retire Signal Desk deliberately, and delete the routine and the artifact together.

I have not touched it. A failed run is harmless — it publishes nothing and leaves the existing briefing intact — but it will fail every night until one of the above happens.
